## 👨‍💻 About me

I'm **Encrypted**, a full-stack developer and CEO of **[atPay](https://atpay.ng)**, based in Nigeria. I build web and mobile applications, work with fintech APIs, and enjoy turning practical problems into products people can use.

My background in **networking and cloud computing** shapes how I think about connected systems. Alongside product development, I'm growing my skills in **Python, cybersecurity, and IoT**.

- 🔭 **Current focus:** Building atPay and improving web, mobile, and API experiences.
- 🤝 **Open to collaboration:** Fintech apps, Flutter projects, and useful developer tools.
- 💬 **Ask me about:** PHP, Flutter, API integration, and building app businesses.
- 🌱 **Learning mindset:** Build, test, understand, and improve.
